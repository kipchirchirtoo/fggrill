BACKEND FIX APPLIED!

Room booking validation is now fixed

🔧 What Was Fixed

The backend was using different room status filters for searching vs booking:

  • Search: Only showed rooms with status 'available' or 'cleaning'
  • Booking: Accepted any room not in 'maintenance' or 'out_of_order'

This caused rooms to appear in search but fail during booking. Now both use the same filter.

🎯 How to Test

1 Open the landing page:
Open Landing Page
2 Fill in the booking form:
  • Select a branch (e.g., "Kyogong")
  • Pick check-in date (today or future)
  • Pick check-out date (after check-in)
  • Select number of guests
3 Click "Check Availability"
You should see a success toast message and the page will scroll down to show available rooms
4 View the room cards
Each room card shows:
  • Room number and type
  • Price per night
  • Amenities (King Bed, WiFi, TV, Minibar)
  • "Reserve This Room" button ← THIS IS THE "VIEW ROOM OPTION"
5 Click "Reserve This Room"
A modal will open where you can enter guest details and complete the booking
