## Validation Status

- Route parity: partial globally. Central Store and Superadmin are now directly GoRouter-addressable; remaining dashboards still need nested route passes.
- API parity: partial. Auditor and central store have active repositories; several dashboards still need method-by-method contract mapping.
- Modal/action parity: partial globally. Central Store and Superadmin action dialogs have been verified; remaining dashboards still need execution passes.
- UI parity: Superadmin and Admin shells differ slightly; target standard is documented in `docs/flutter/ui_design_system.md`.
