# 🚀 Leave Management - Quick Start Guide

## 📍 How to Access

1. Login as **Branch Manager**, **Auditor**, or **HR Manager**
2. Navigate to: **Branch Manager → Staff → Leave Management**
3. The page will show all leave requests for your branch

---

## ✨ Key Features at a Glance

### Dashboard Stats
- **Total Requests** - All leave requests
- **Pending** - Awaiting approval (yellow badge)
- **Approved** - Accepted requests (green badge)
- **Rejected** - Declined requests (red badge)

### Leave Types
- 🏖️ **Annual Leave** - Regular vacation
- 🤒 **Sick Leave** - Medical leave
- 🤰 **Maternity Leave** - For expecting mothers
- 👶 **Paternity Leave** - For new fathers
- 💰 **Unpaid Leave** - Leave without pay
- 📋 **Other** - Special circumstances

---

## 📝 How to Submit a Leave Request

1. Click **"New Request"** button (top right)
2. **Select Employee** from dropdown
3. **Choose Leave Type** (annual, sick, etc.)
4. **Pick Dates**:
   - Start Date
   - End Date
   - System automatically calculates duration
5. **Add Reason** (optional but recommended)
6. Click **"Submit Request"**
7. ✅ Done! Request is now pending approval

---

## ✅ How to Approve/Reject Requests

1. Find the request in the table
2. Click the **eye icon** (👁️) to view details
3. Review:
   - Employee information
   - Leave type and duration
   - Dates and reason
4. Click:
   - **"Approve"** button (green) to accept
   - **"Reject"** button (red) to decline
5. ✅ Status updates immediately

---

## 🔍 Search & Filter

### Search Bar
- Type employee name: "John Doe"
- Type employee ID: "FG01001"
- Results filter in real-time

### Status Filter
- **All Status** - Show everything
- **Pending** - Only awaiting approval
- **Approved** - Only accepted requests
- **Rejected** - Only declined requests
- **Cancelled** - Only cancelled requests

## 🆘 Troubleshooting

### "No leave requests found"
- ✅ Check if you have staff in your branch
- ✅ Try changing the status filter to "All Status"
- ✅ Clear the search bar

### "Failed to submit leave request"
- ✅ Ensure all required fields are filled
- ✅ Check that end date is after start date
- ✅ Verify employee is selected

### "Failed to approve/reject"
- ✅ Check your internet connection
- ✅ Verify you have permission (Branch Manager, Auditor, or HR)
- ✅ Refresh the page and try again
