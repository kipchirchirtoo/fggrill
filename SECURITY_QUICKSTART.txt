ISSUE: IPs still showing as localhost (::1)
FIX: Configure reverse proxy to forward real IPs
     (See SECURITY_SETUP.md for nginx config)

ISSUE: Geolocation not working
FIX: Check server internet connectivity
     Verify ip-api.com is accessible
     Consider upgrading to paid service

ISSUE: Too many false positives
FIX: Whitelist office/branch IPs
     Adjust threat score thresholds
     Review detection rules
